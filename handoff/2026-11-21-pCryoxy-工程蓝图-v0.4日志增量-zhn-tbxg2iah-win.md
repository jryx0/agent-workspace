## 1. 新增模块边界

新增 PC-21 日志与可观测性领域，位于 daemon 事件汇聚和本地存储层：

```text
PC-04 Go bridge / PC-08 RPC / PC-09 scheduler
        │ 受控 AccessObservation / NodeHealthObservation
        ▼
PC-18 daemon 单写者与生命周期
        ▼
PC-21 logging model / redact / bounded queue / store / retention
        ├── 本地 JSONL 或等价版本化存储
        └── 日志查询服务
                ▼
PC-20 HTTP/WS/auth 路由
        ▼
PC-15 SolidJS Web 页面或 Tauri 页面
```

PC-04 只产生受控路由和性能观测，不直接写 Web、不直接管理日志文件；PC-21 不复制 Go/Xray 的路由决策逻辑。

## 2. 日志事件和普通 SafeEvent 分离

现有 `SafeEvent` 继续用于前端通用状态、AI 安全投影和非敏感事件，不增加域名、URL、进程路径或凭据字段。

新增 `AccessLogRecord` 仅用于本地受鉴权日志查询，字段经过专门构造器白名单投影。默认包含域名级目标和策略/节点/性能字段，不包含 HTTPS path、query、正文、请求头、Cookie、Authorization、ticket、SecretRef 或原始错误。

访问日志不得自动进入：

- AI SafeContext；
- 第三方遥测；
- 崩溃上报；
- 远程同步；
- 普通错误字符串。

## 3. 存储和生命周期

初始实现采用可版本化的本地结构化日志存储，允许 JSONL 按日或按大小滚动。磁盘格式不等于前端 DTO，必须包含格式版本，查询器遇到未知版本应安全拒绝或降级，不得猜测字段。

日志写入通过有界异步队列，不得在代理转发线程同步等待磁盘。队列满、磁盘满、文件损坏和权限不足必须有明确安全状态；访问明细可按策略丢弃或采样，但关键启动、停止、清理和写入失败事件必须有独立记录。

保留策略：

```text
retentionDays
maxTotalBytes
rotatePolicy
startupCleanupMode = none | expired | all_previous
```

启动清理在新日志文件创建前执行；`all_previous` 不删除本次启动新建日志。默认值由契约提交冻结，当前仅将 `expired` 作为安全实现建议，不写成用户已裁定固定值。

Windows 使用服务身份 ACL；Linux 使用专属服务账户、目录至少 0700、日志文件至少 0600。具体数据目录由 PC-10/PC-19 冻结，并在服务重启、异常退出和升级回退中保持归属。

## 4. Web 查询边界

P0 Web 管理端支持历史日志查询、统计、筛选、导出和受控清理，不要求 P0 实时 tail。实时 tail 可在有界事件队列和丢弃/重同步语义冻结后作为后续增量。

默认绑定回环地址。非回环监听延续 v0.3 的管理员 Token、Origin、会话失效和禁止 Token 入 URL/日志/构建物约束。

Web 只能调用统一业务处理器，不得直接读日志文件、调用官方 Xray RPC、读取 vault 或执行任意路径。

## 5. 应用来源归属

日志字段允许 `sourceApp = null/unknown`。Windows/Linux 只在平台确有连接到进程的证据时记录进程名、UID、PID 快照或受控应用标识；不得从域名、端口或策略组反推应用。

Windows WFP/连接-PID 映射、Linux UID/cgroup/socket owner/conntrack/eBPF 属后续平台能力。既有 Windows TUN/进程分流 P1 卡不因本增量提前变为 P0。

## 6. 依赖拓扑增量

```text
PC-02 公开 DTO / 统一 REST-WS-Tauri 契约
  ├─ PC-04/08/09 受控观测源
  ├─ PC-18 daemon 生产宿主
  ├─ PC-19 Windows/Linux 服务与权限
  └─ PC-21 日志存储与查询领域
          └─ PC-20 Web REST/WS/auth 适配
                  └─ PC-15 日志页面与统计展示
```

PC-21 不得直接改 PC-02 公共 DTO、PC-20 HTTP/WS 适配、PC-18 `lib.rs` 或 PC-19 平台安装文件；需通过最小变更申请串行接入。

## 7. 非目标

本增量不包含：

- TLS 中间人解密；
- HTTPS 完整 URL path/query 默认采集；
- 远程公网日志平台；
- 云端日志同步；
- Android/iOS/鸿蒙 NEXT 日志统一实现；
- 以日志能力替代真实节点、服务、TUN 或进程分流验收。
