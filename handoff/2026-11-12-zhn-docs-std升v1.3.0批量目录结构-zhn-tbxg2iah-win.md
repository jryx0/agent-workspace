**七项确认结论（全部按推荐）**

| # | 决策点 | 结论 |
|---|---|---|
| Q1 | 批次目录名 | = 本批次共同主题/任务短名（如 `重建`），与文件名「类型段」是两个独立概念；不带日期前缀；复用 §3 长度与字符约束；≥4 字走 §4 确认；不做同主题标签复用提示；不给候选列表 |
| Q2 | 分隔符 | 沿用全角 `｜`（U+FF5C），例子的半角 `|` 与文件名前空格视为简写；§2 补「不使用半角 `|`、文件名前不留空格」 |
| Q3 | 索引文件 | 按任务需要可能生成、非必选不强制；生成时与其他主文件完全同规则命名；不额外要求 `index.md` / `README` |
| Q4 | 触发阈值 | 产出到 agent-docs 的文件数 ≥2（主文件/索引文件 + 关联文件合计）启用；恰好 1 个文件不建批次目录；无关联文件不建空子目录 |
| Q5 | 关联文件与子目录 | 关联文件豁免 §2、保持原名；只建一个关联子目录、固定一层不嵌套；目录名只推荐一个、尽量简短（2–3 汉字或单个英文词） |
| Q6 | 撞名与扫描 | 放宽为「输出方案时提示调用方对用户指定目标路径下一层做一次只读查看（不递归、不列全库、不写）」；同名批次目录给「复用／换名」二选一并等确认；**本技能自身不执行该查看** |
| Q7 | 职责边界 | 保持纯规范型：本技能只输出方案，实际创建目录与文件由调用方执行 agent 完成；§7 补「不创建（含目录）、不执行工具调用」；既有「目录名≈文件名」旧目录只兼容、不迁移、不改名 |

**三处含糊点按默认处理（可逆，一句话可改）**：① 批次目录名与关联子目录名统一复用 §3 长度/字符约束与 §4 的 ≥4 字确认流程，不另设一套规则；② 同批主文件 YYMMDD 取同一个「保存到 agent-docs 的当日」，主题段须互相区分；③ 用户指定的目标路径是既定前提，技能不推断、不改写、不往上加层，路径不存在由执行 agent 创建。
