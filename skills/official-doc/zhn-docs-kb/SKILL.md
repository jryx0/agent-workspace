# zhn-docs-kb — 多 Agent 协同共享文档知识库

## 0. 状态（v0.1.0 草案，先读这段）

- 本技能依据 2026-11-12《飞书 + 百度网盘混合存储方案审核》（`docs://技术资料/261112｜文档｜飞书百度网盘混合存储方案审核.md`）建立。
- **外部后端尚未接入实测**：飞书 MCP/API、百度网盘官方 Skill 的可用性、限速、容量均为 TBD（见第 10 节）。
- 因此在人类完成裁决与冒烟测试前，本技能仅允许：**本地分层判断、命名、索引设计、只读检索**；不允许自动上传外部云、不允许生成分享链接。
- 上位约束：`~/.agent-shared/global/rules.md`（二-3 单一原件、三-3 分类、四-1 安装、三-5 ⑥ 云同步目录人类 UI 操作）。冲突时以上位规范为准。

## 1. 分层与 URI

| 层 | 位置 | URI | 角色 | 原件归属 |
|---|---|---|---|---|
| 文本源码层 | `~/.agent-shared`、项目仓 | Git 路径 | ≤1MB 文本/代码/技能/规范 | 原件 |
| 活跃文档层 | `~/.agent-docs` | `docs://<相对路径>` | Office/PDF/md/html 文档、跨设备同步 | **原件唯一** |
| 大文件归档层 | NAS `Z:\`（22T，已挂载） | `nas://<相对路径>` | >100MB、二进制、冷数据、Agent 高频读的大文件 | 原件 |
| 外部交付层 | 百度网盘 `/apps/bdpan/` | `pan://<相对路径>` | 对外分享、异地冷备 | **仅副本** |
| 在线协作层（可选） | 飞书云空间 | `feishu://<file_token 或路径>` | 在线预览、多人协作 | **仅副本** |
| 索引层 | 飞书多维表格（正式）/ `~/.agent-docs/kb/`（过渡） | `kb://` | 统一检索入口 | 索引而非文件 |

- 大文件中转只用 NAS；百度网盘不承担「Agent 高频自动读取的大文件层」。
- 索引权威位置二选一，由人类裁决；未裁决前用过渡位置，不自建第三套索引。

## 2. 单一原件原则

- 每个文件有且仅有一个 authoritative 原件位置；其他位置只能是副本/缓存，索引中 `copy_of` 必填。
- 修改只改原件，再按需重新生成副本；禁止在副本上单独修改形成双活。
- 若要把活跃层原件迁往飞书，属于架构迁移：需人类明确批准，并同步修订 rules.md 二-3 与设备档案，不得默认发生。

## 3. 命名约束（强制委派 zhn-docs-std）

- 进入知识库的**主文件/索引文件**一律按 `YYMMDD｜类型｜主题.扩展名`；批量 ≥2 文件按 zhn-docs-std v1.3.0 §5（批次目录 + 主文件 + 唯一关联子目录，关联文件保持原名）。
- 命名、类型段归纳、≥4 字确认、撞名核对，全部调用 `zhn-docs-std` 完成；本技能不自行发明标签、不替用户确认。
- 上传飞书/百度网盘的副本**沿用原件文件名与相对路径**，不在云端另起命名体系；类型段、YYMMDD、批次目录同时写入索引字段。
- 引用知识库文件时使用第 1 节 URI，不写本机绝对路径。

## 4. 索引

- 字段：`doc_id`、`文件名`、`yymmdd`、`类型段`、`主题`、`批次目录`、`相对路径`、`后端`、`后端路径或 file_id`、`size`、`sha256`、`mime`、`密级`、`copy_of`、`status`、`origin_device`、`origin_agent`、`created_at`、`updated_at`、`share_state`、`tags`。
- `doc_id` 由 `sha256 + 后端 + 后端路径` 派生，保证重复写入幂等；`status ∈ active / pending / pending_orphan / missing`。
- 分享链接默认不写入索引；确需记录时只记链接与 `share_state`，**提取码永不落索引、Git、共享记忆、handoff**。

### 4.1 写入流程（两阶段，可恢复）

1. 本地：命名 → 流式计算 sha256 → 索引查重 → 写 `status=pending`。
2. 上传目标后端 → 回读元数据核对大小/校验值 → 置 `active`。
3. 任一步失败：置 `pending_orphan` 并报告人类；不自动重传、不自动删除。
4. 同一文件再次写入：sha256 相同则去重并复用记录；同名不同 sha256 走 zhn-docs-std 撞名流程，等待人类确认。

### 4.2 检索与取回

- 先查索引，再按 `后端` 与 URI 取回；禁止逐后端盲搜作为默认策略。
- 缓存到本会话工作区临时目录，按 sha256 命中复用；用毕清理，不在共享仓堆积二进制。
- 大文件只从 NAS 取；百度网盘仅在副本交付/恢复场景使用。

### 4.3 对账

- 只读比对索引与后端列表，输出孤儿（后端有、索引无）与缺失（索引有、后端无）清单交人类。
- 对账只报告，不自动修复、不自动删除。

## 5. 分流判断（按顺序取第一个命中项）

1. 密级 secret → 仅本机/指定安全位置，**禁止外云与分享**，流程终止并提示。
2. 文本/代码 ≤1MB 且属规范/技能/脚本源码 → Git。
3. >100MB、二进制、或 Agent 需高频读的大文件 → NAS（`nas://`）。
4. 文档原件且需跨设备 → `~/.agent-docs`（`docs://`），命名按第 3 节。
5. 需在线预览/多人协作 → 另存飞书副本（`copy_of` 指向原件）；md 导入为飞书文档，html 不承诺在线预览。
6. 对外交付或异地冷备 → 百度网盘副本（`pan://`），默认不生成分享链接。
7. 飞书上传：≤20MB 单请求；>20MB 必须分片。

## 6. 安全红线

- 密级：`public / internal / confidential / secret`。secret（账号、密钥、Token、证件等）禁止上传外部云、禁止生成分享链接。
- 分享：默认关闭；仅当人类当次明确指令才生成，优先 1 天/7 天有效期 + 提取码；链接与提取码只在当次回复给人类，不写入任何入库文件。
- 凭证：飞书 `app_secret` 等放 `~/.agent-shared/config/`（0600，禁 Git）；百度网盘 Token 由官方 CLI 配置文件管理，**Agent 禁读、禁输出、禁转发**；授权码经 stdin 传递。
- 安装：先 `bash ~/.agent-shared/env/tools-scan.sh --check`；禁全局/用户级安装；通用库进 `~/.agent-tools/venvs/<agent名>/`；项目 CLI 用 devDependency + lock + npx。
- 云同步目录内的删除、移动、冲突处理由人类在客户端 UI 完成；Agent 只提供待处置清单。

## 7. 平台与依赖约束

- 百度网盘官方 Skill（`BaiduNetdiskAIBot/bdpan-storage`，公测 BETA）：支持 macOS / Linux / **Windows WSL**；**Windows 原生不支持**，禁止在本机原生环境尝试安装或绕行。只能在 WSL2 或 Linux 设备上执行，且需人类本人扫码授权。
- 网盘操作范围仅 `/apps/bdpan/`；删除、移动、重命名、覆盖需人类明确确认。
- 飞书：官方 `@larksuiteoapi/lark-mcp` 需 Node≥20 与企业自建应用；MCP 预设工具集是否覆盖 Drive 上传/下载未实测，缺失时改走 Drive OpenAPI，不伪造能力。
- 新增 MCP Server 后需人类在连接器管理页点「信任」才生效。

## 8. 多 Agent 协同

- 任务认领：`memory/org.md` 追加 `[doing]`（任务ID / owner / worktree / 锁定文件），完成后 `[done]`；涉他任务留 handoff。
- 同一文件同一时间只允许一个 owner 写；索引写入按 `doc_id` 幂等，冲突不覆盖他人记录。
- 不改他人未提交改动；共享仓提交只 `git add` 自己产出的路径，禁止 `git add -A`。
- 跨设备引用一律用 URI；Linux/Termux 无法解析的载体要注明替代获取方式。

## 9. 限流与退避

- 网络/限流失败：指数退避（1s→2s→4s→8s→16s，至多 5 次），记录 HTTP/CLI 错误码与触发阈值。
- 批量操作串行并加间隔，不并发打满配额；连续失败即停，报告人类，不更换未授权通道绕过。
- 大文件传输记录起止时间与速度，写入当次任务报告（速度数据属于实测记录，不入长期记忆）。
